# Programming Patterns

Variety of programming patterns.

## Installation

Add this git repository URL to your Unity project's Packages/manifest.json:

```json
"dependencies": {
    "com.greeny.patterns": "git+https://github.com/JibbeGreen/ProgrammingPatterns.git"}
```

## Dependencies

Requires Unity 6000.6 or newer.

Must be installed manually (git / third-party, cannot be declared in `package.json`):

- Unity Utils (com.gitamend.unityutils): https://github.com/adammyhre/Unity-Utils (used by the Mediator and ServiceLocator assemblies)
